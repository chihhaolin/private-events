# Project Scope

本專案要做到 **Tier 1 + Tier 2 + Tier 3**。Tier 4 不在範圍內。

---

## Tier 1｜最小可動

對應 Odin Step 1–3。完成這層即達成「練習自訂 ActiveRecord 關聯」的核心學習目標。

- 使用者註冊 / 登入 / 登出
- 建立活動（活動有建立者 creator）
- 報名活動 / 取消報名
- 活動列表頁、活動詳情頁（顯示參加者）
- 個人 profile：列出「我建立的活動」「我參加的活動」

---

## Tier 2｜Odin 完整版

對應 Odin Step 4。在 Tier 1 之上加：

- 活動列表與個人 profile 都要把活動分成「過去」「未來」兩區
- 加上頂部 navbar
- 私人活動：建立者可以把活動設為私人，並邀請特定使用者參加
  - 邀請是新一組關聯，跟「報名」是兩回事

---

## Tier 3｜Extra Credit

完整 CRUD 與權限判斷：

- 建立者可以編輯 / 刪除自己建立的活動
- 使用者可以取消自己對某活動的報名
- 建立者可以切換活動的公開 / 私人狀態

---

## 不做（Out of Scope）

下列功能留給之後的練習，不在這個專案處理：

- 活動圖片上傳
- 活動搜尋 / 分類 / 標籤
- 活動留言
- Email 通知
- 地圖 / 地點選擇
